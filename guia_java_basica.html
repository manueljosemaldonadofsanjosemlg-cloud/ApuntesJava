1. Estructura básica de Java

Un programa Java normalmente comienza con una clase y dentro de ella se encuentra el método main. El método main es el punto donde empieza a ejecutarse el programa. 

public class Main {

    public static void main(String[] args) {

        System.out.println("Hola mundo");

    }

}
El nombre del archivo debe coincidir con el nombre de la clase. Si la clase se llama Main, el archivo debe llamarse Main.java.

2. Mostrar texto por pantalla

Para mostrar información usamos principalmente System.out.println().

System.out.println("Hola");

println y print

System.out.print("Hola ");
System.out.print("Manuel");

4. Leer datos con Scanner

Scanner permite que el usuario introduzca información mediante el teclado. 

import java.util.Scanner;

public class Main {

    public static void main(String[] args) {

        Scanner teclado = new Scanner(System.in);

        System.out.println("Introduce tu edad:");
        int edad = teclado.nextInt();

        System.out.println("Tienes " + edad + " años");

    }

}

Métodos habituales de Scanner

  • nextInt() → leer un número entero.
  • nextDouble() → leer un decimal.
  • next() → leer una palabra.
  • nextLine() → leer una línea completa.

6. Condiciones: if / else

Permiten ejecutar un código dependiendo de si una condición es verdadera o falsa. 

int edad = 20;

if (edad >= 18) {

    System.out.println("Eres mayor de edad");

} else {

    System.out.println("Eres menor de edad");

}

Else if

int nota = 7;

if (nota >= 9) {

    System.out.println("Sobresaliente");

} else if (nota >= 5) {

    System.out.println("Aprobado");

} else {

    System.out.println("Suspenso");

}

7. Switch

switch es útil cuando queremos comprobar diferentes valores posibles de una misma variable. 

int opcion = 2;

switch (opcion) {

    case 1:
        System.out.println("Has elegido la opción 1");
        break;

    case 2:
        System.out.println("Has elegido la opción 2");
        break;

    default:
        System.out.println("Opción incorrecta");

}

8. Bucle for

El bucle for sirve para repetir código un número determinado de veces. 

for (int i = 1; i <= 5; i++) {

    System.out.println("Número: " + i);

}

Resultado:

Número: 1
Número: 2
Número: 3
Número: 4
Número: 5

9. Bucle while

El bucle while se repite mientras se cumpla una condición. 

int numero = 1;

while (numero <= 5) {

    System.out.println(numero);

    numero++;

}

10. Arrays

Un array permite guardar varios valores del mismo tipo dentro de una sola variable. 

int[] numeros = {10, 20, 30, 40};

System.out.println(numeros[0]);
System.out.println(numeros[1]);
Las posiciones de un array empiezan en 0.

Recorrer un array

int[] numeros = {10, 20, 30};

for (int i = 0; i < numeros.length; i++) {

    System.out.println(numeros[i]);

}

11. Métodos

Los métodos nos permiten separar el programa en pequeñas partes reutilizables. 

public class Main {

    public static void saludar() {

        System.out.println("Hola desde un método");

    }

    public static void main(String[] args) {

        saludar();

    }

}

Método que devuelve un valor

public static int sumar(int numero1, int numero2) {

    return numero1 + numero2;

}

Uso:

int resultado = sumar(5, 3);

System.out.println(resultado);

12. Ejemplo completo

Este programa pide el nombre y la edad del usuario y después indica si es mayor de edad. 

import java.util.Scanner;

public class Main {

    public static void main(String[] args) {

        Scanner teclado = new Scanner(System.in);

        System.out.println("Introduce tu nombre:");
        String nombre = teclado.nextLine();

        System.out.println("Introduce tu edad:");
        int edad = teclado.nextInt();

        System.out.println("Hola " + nombre);

        if (edad >= 18) {

            System.out.println("Eres mayor de edad");

        } else {

            System.out.println("Eres menor de edad");

        }

        teclado.close();

    }

}
